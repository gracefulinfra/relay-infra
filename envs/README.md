# Environments

Each directory here is a Kustomize overlay that Argo CD's `relay-root` Application reconciles.
`platform/` holds only provider-neutral manifests. **Anything that differs by provider is patched in
here and nowhere else.** A new environment copies an overlay and changes the knobs below.

| Env | Status |
| --- | --- |
| `local` | k3d on a laptop (`make up`). Real values. |
| `provider-a`, `provider-b` | Compile-only stubs (P0-05). Every provider value is a placeholder: an `*.example` domain (RFC 2606) or `PLACEHOLDER_*`. P0-07 makes one of them real. |

## Provider knobs

Each knob is listed with the base manifest it patches, what `local` sets, and what a provider overlay must set.

| Knob | Base manifest | `local` | Provider overlay |
| --- | --- | --- | --- |
| **Base domain** | `Gateway/relay` listener hostnames and every `HTTPRoute.spec.hostnames` (base placeholder `relay.example.invalid`) | `*.relay.localtest.me`, which public DNS resolves to 127.0.0.1 | The env's real wildcard domain |
| **DNS** | none (outside the cluster) | Nothing to do (localtest.me) | A wildcard record pointing at the load balancer (ExternalDNS or manual; not in this slice) |
| **Load balancer** | `EnvoyProxy/relay-proxy` `.spec.provider.kubernetes.envoyService` | `type: LoadBalancer` served by k3s klipper servicelb; k3d maps host ports 80/443 | The provider's LB annotations (scheme, IP family, health checks), and optionally `loadBalancerClass` |
| **TLS issuer** | `ClusterIssuer/relay-issuer` `.spec` (base is empty) | `ca:` over the script-generated local CA (`$RELAY_HOME/ca`, synced by `ExternalSecret/relay-local-ca`) | `acme:` with a DNS-01 solver (wildcards need DNS-01); the solver is provider-specific |
| **Secrets backend / KMS** | `ClusterSecretStore/relay-secrets` `.spec.provider` (base is empty) | ESO `kubernetes` provider reading `relay-secret-source`, which `scripts/secrets.sh` fills | The provider's secret manager (KMS-backed) or a Vault-API endpoint. `ExternalSecret`s never change; only the store does |
| **Storage class** | PVC-bearing charts (P0-05 PR2: CNPG, SeaweedFS) | k3s `local-path` (default class) | The provider's block storage class |
| **S3 endpoint and credentials** | Consumers of the `relay-s3` secret (P0-05 PR2) | In-cluster SeaweedFS S3 gateway; credentials generated by `scripts/secrets.sh` | The managed S3 endpoint, region, and credentials in the secret manager |

Rules:

- A knob is added to this table in the same PR that introduces it.
- `platform/` must stay free of provider names, hostnames, and credentials. `make test` renders every
  overlay (provider stubs included) and validates it with kubeconform.
- Secrets are never in git in any form. A provider overlay points the `ClusterSecretStore` at its
  backend; the values are loaded there out of band.
